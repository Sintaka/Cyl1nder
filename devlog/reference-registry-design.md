# 引用登记表：改名安全的地址系统（v0.1.00117）

> 照抄 Houdini 的真实机制。研究方法：在 Houdini 22.0.368 实机搭探针
> （`/obj/RENPROBE` 等）逐项验证，用完销毁；**未保存 hip**。
> 关联：`project-mapping-design.md`（映射系统）· `development-standards.md`（中间省略铁律）

## 0 问题

`/P1-…/geo1` 结构里，在项目根把 `geo1` 改名成 `geo2`，内部引用（映射 `rel`、
object merge 式的节点引用）必须自动跟随。Houdini 有这个能力，我们要对齐。

## 1 Houdini 到底怎么做的（实机验证）

**不是求值时解析，是改名时推送重写。**

Houdini 不把节点引用存成"指针"，它存**你输入的那串字面量**，同时维护一张
**名字依赖登记表**：每个「文本里提到了某节点」的参数都被登记。改名时遍历该表，
**逐条文本重写**。

读出登记表的入口（实机确认存在）：
- `hou.OpNode.parmsReferencingThis()` → 引用本节点的 `hou.Parm` 元组，就是登记表读出口
- `opdepend -N <node>` → 名字依赖者；`-n` 名字引用（对比 `-i`/`-o` 是 cook 依赖，两套系统）
- `hou.NetworkMovableItem.setName()` → 触发重写的入口；重写在改名的 undo block 内（原子）

### 只有「登记过的」才会被重写

参数靠 `stringType` 决定是否登记：`NodeReference`（如 `object_merge.objpath1`，
tags `{opfilter:'!!SOP!!', oprelative:'.'}`）与带 `op:` 的 `FileReference` 会被登记；
普通 `Regular` 字符串参数**不会**，即使内容是一条完全合法的节点路径。

实测同一串路径的不同载体，改名后结果相反：

| 载体 | 改名后 |
|---|---|
| `object_merge.objpath1`（相对/绝对都算） | ✅ 已重写 |
| `ch("../../zzsrc/tx")` / `centroid("…")` 表达式字面量 | ✅ 已重写 |
| VEX snippet 里的 `point("…/zzsrc/OUT", …)` | ❌ 静默失效 |
| Python SOP 里的 `hou.node('…')` | ❌ 静默失效 |
| 拼接表达式 `"/obj/EXT" + "_R/extbox"` | ❌ 静默失效，且**节点不报错** |

VEX 里那串和 `centroid()` 里那串**字节完全相同**，一个被重写一个没有——
判据是**是否登记**，不是文本匹配。

### 两条值得照抄的性质

1. **悬空引用会自愈**：登记表记的是「名字字符串」而非活指针。把引用指向一个还不存在的
   名字，之后真把某节点改成那个名字，引用即刻解析成功。
2. **相对与绝对在改名上完全等价**（都登记、都重写）；差别只在结构性变动：
   子网内自包含引用用相对（复制后指向副本自己），跨出去指固定设施用绝对。

## 2 我们照抄什么

`web/src/nodes2/ref-registry.ts`：

- **登记制**：`register(site, ref)` 显式登记引用点。**不扫描**节点参数猜哪个像路径——
  猜测正是 Houdini 明确不做的事，也是它失效模式清单的来源。
- **改名即重写**：`rewriteOnRename(oldName, newName)` 遍历登记表逐条重写，返回改了几条。
- **前缀边界**：`geo1` 改名不能碰到 `geo10`。按路径段边界匹配（`geo1` 或 `geo1/...`），
  不做裸子串替换。
- **`audit()`**：改名前可查「谁引用了它」，对应 `parmsReferencingThis()`。
  **未登记 = 不会被重写**，这一点必须在 UI 上说清楚，而不是假装全都保得住。

| 关系 | 说明 |
|---|---|
| **映射系统**（`mapping.py`） | 桥侧「逻辑名 → 相对地址」，锚点 = 吊牌 serial。锚点移动由**吊牌 cook 上报**驱动 |
| **引用登记表**（`ref-registry.ts`） | web 侧「谁引用了哪个节点」，改名由**用户在 nodeview 操作**驱动 |

两者解决的是同一类问题的两端：映射系统扛 **Houdini 侧**节点移动，
引用登记表扛 **web 侧**节点改名。都遵循同一条原则：
**引用存逻辑标识，不存易变的绝对路径**。
