# Params 面板操作指引（用户手册）

> 位置：Web 前端左侧 Params 面板（选中节点后显示该节点参数表）
> 适用范围：transform 节点 tx/ty/tz/px/py/pz/group/class 等全部参数；其他节点预留
> 版本：v0.1（分支 codex/cyl1nder-v0，2026-08-11）

## 1. 中键拖拽倍率 scrubbing（数值框）

| 项 | 说明 |
|---|---|
| 触发 | 在数值输入框上按住**中键（MMB）**不放 |
| 浮层 | 7 档倍率竖排（100 / 10 / 1 / **0.1** / 0.01 / 0.001 / 0.0001），以鼠标为垂直中点出现，**0.1 行正好在鼠标处**（默认倍率 0.1，第 4 行高亮） |
| 框内（未出框） | **上下移动只切换倍率高亮行，不更改数值** |
| 出框（跨过左/右边缘） | 倍率锁定为当前高亮行；此后**只有左右拖动改数值**，上下拖动无效（也不切倍率） |
| 灵敏度 | **左右减半**：数值变化 = 累计水平位移 × 倍率 × 0.5 |
| 轨迹归一化 | 以“出框点”为基准累计水平位移（value = 起始值 + 累计位移 × 倍率 × 0.5），位置基准、无抖动跳变 |
| 结束 | 松开中键关闭浮层；浮层底部显示当前值（最多 4 位小数） |

示例（倍率 0.1、灵敏度 0.5）：出框后右移 20px → 数值 +20×0.1×0.5 = **+1**。

## 2. Ctrl + 中键单击恢复默认值

| 项 | 说明 |
|---|---|
| 触发 | 在数值框 / 文本框 / class 下拉框上 **Ctrl + 中键单击** |
| 默认值来源 | 优先用参数显式 default；缺失时按类型兜底（float/int → 0；class → autoguess；其他 string → ""） |
| 效果 | 立即写回控件并走正常提交路径（可撤销） |
| transform 节点 | 全部参数都有默认值：tx/ty/tz/px/py/pz → 0，group → ""，class → "autoguess" |

## 3. 键盘直接输入

| 操作 | 说明 |
|---|---|
| 点击数值/文本框 | 直接输入数字或文本，输入 / 回车 / 失焦即提交（走同一提交路径） |
| class 下拉 | 从 autoguess / points / vertices / prim / detail 中选择 |
| 说明 | 键盘输入同样记录撤销，且不会与中键 scrubbing 冲突 |

## 4. 撤销 / 重做

| 键 | 动作 |
|---|---|
| Ctrl+Z | 撤销上一步（含参数修改） |
| Ctrl+Shift+Z / Ctrl+Y | 重做 |

- 参数面板的数值修改（键盘输入、scrubbing、Ctrl+中键恢复默认值）与节点拓扑操作共用同一撤销栈。
- 撤销/重做参数修改后会自动重跑网络并刷新面板。
